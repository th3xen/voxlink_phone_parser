````markdown
# voxlink_phone_parser

Парсер телефонных номеров для сервиса
https://num.voxlink.ru/

Программа читает номера из CSV-файла, отправляет HTTP-запросы к API и сохраняет результат в файл `output.csv`.

````
# Сборка

```bash
go build .
```


Будет создан исполняемый файл.

---

# Быстрый запуск (без сборки)

```bash
go run app.go
```

# Как использовать

## 1. Подготовить файл с номерами

В директории, где находится `app.go`, создайте файл:

```
input.csv
```

Пример содержимого:

```
78005553535
78005553535
78005553535
```

Каждый номер — **с новой строки**.

---

## 2. Запустить программу

```bash
go run app.go
```

или, если собран бинарник:

```bash
./voxlink_phone_parser
```

---

## 3. Дождаться завершения

После завершения работы будет создан файл:

```
output.csv
```

---

# Формат результата

Результаты записываются в CSV следующего вида:

```
Номер,Статус,Оператор,Регион,Код,Полный номер,Ошибка
78005553535,Успешно,МТТ,Российская Федерация,800,8005553535,
79509710359,Успешно,Т2 МОБАЙЛ,Красноярский край,950,9509710359,
```

### Поля

| Поле         | Описание                                     |
| ------------ | -------------------------------------------- |
| Номер        | исходный номер из `input.csv`                |
| Статус       | результат проверки                           |
| Оператор     | оператор связи                               |
| Регион       | регион номера                                |
| Код          | код оператора                                |
| Полный номер | номер без префикса                           |
| Ошибка       | сообщение об ошибке, если запрос не выполнен |

---

# Примечания

* Программа соблюдает ограничение API: **не более 10 запросов в секунду**.
* Используются **таймауты HTTP-запросов**.
* Все ошибки сети и API записываются в колонку **Ошибка**.
